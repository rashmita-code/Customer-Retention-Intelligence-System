\# Customer Retention Intelligence System



\## 📌 Overview

This project aims to predict whether a customer will churn (leave a service) based on their usage patterns and account information. Customer churn prediction helps businesses take proactive steps to retain customers.



\---



\## 🎯 Objectives

\- Perform data preprocessing and cleaning  

\- Analyze customer behavior using EDA  

\- Build machine learning models for prediction  

\- Evaluate model performance using metrics  



\---



\## 📂 Dataset

\- Files:

&#x20; - `churn-bigml-80.csv` (Training Data)  

&#x20; - `churn-bigml-20.csv` (Testing Data)  



\### 🔑 Features include:

\- Account Length  

\- International Plan  

\- Voice Mail Plan  

\- Number of Customer Service Calls  

\- Call Minutes, Charges, and Usage  

\- Target: \*\*Churn (True/False)\*\*  



\---
